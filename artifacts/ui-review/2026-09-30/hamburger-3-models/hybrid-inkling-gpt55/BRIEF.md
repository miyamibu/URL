# Inkling × GPT-5.5 Pro(Web) メニュー案

## Goal

先行2案の視覚要素を組み合わせ、りんばむのハンバーガーメニューを開いた状態の新しい比較用プロトタイプを作る。

## Layout and components

- 390 × 844 CSS px のホーム画面。タイトル左、検索とメニューの順で右上に配置する。
- Inkling案の濃色と簡潔な行構造を使う。右側のメニュー面はヘッダー直下から画面下端まで伸ばし、右端に密着させる。左側には背景のホームを見せる。
- GPT-5.5 Pro(Web)案の暖色、丸いアイコン枠、柔らかいカード表現を必要な範囲で使う。余分な説明文や新しい機能は足さない。
- 現在のメニューは「プロフィール」「画像なし表示に切り替える」「選択」「使い方」の4項目だけ。検索とAIは外側、下部は「グループ」「エクスポート」「＋」「タグ」「アーカイブ」を維持する。

## Tokens and states

- 濃色のメニュー面、明るい文字、暖色のアイコンと選択色。背景は暖色の淡い紙面と白系カード。
- 起動時メニュー開。右上ボタン、Escape、外側クリックで開閉。項目押下は「デザイン確認用」と分かるローカル反応のみを示す。
- 検索ボタンはメニュー外の入力欄を開く。閉状態での背景ホームも崩さない。

## Responsive and accessibility

- 撮影条件は390 × 844 CSS px。狭いプレビュー幅でも横スクロールを出さず、メニュー4項目が読める。
- メニューボタン・項目・下部アクションに意味のある読み上げ名を付け、主要操作のタップ領域を44 CSS px以上にする。
- フォーカス表示、開閉状態のARIA、reduced motionを考慮する。

## Risks and validation

- 暗幕が右上ボタンを覆う、濃色面の文字が低コントラストになる、右端・下端に隙間ができる、4項目以外を追加することを防ぐ。
- サイドパネルで表示と開閉・項目反応を確認し、390 × 844pxのPNGを保存する。これはブラウザ用デザイン案でありネイティブアプリの機能証拠ではない。
